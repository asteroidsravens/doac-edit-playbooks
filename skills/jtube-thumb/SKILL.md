# JTube thumb (post-pack)

Use when you need a thumb after JTube, or when a Short is Drive-QA ready and needs a click-reason still.

## Rules
- **Never stretch** the base photo. Scale to cover, center-crop (bias to faces/eyes).
- Left readability: soft **fade/blur of the same image** into the type column — not a hard black split or blacked-out block.
- Type: heavy condensed ALL-CAPS (Anton or equivalent), white + one gold punch word/line, black stroke. Stack on the left with air between lines. Keep type off faces when possible.
- Framerate/size for Shorts: **1080×1920** JPG.
- Copy must answer **WHY click** in ≤3 short lines — curiosity gap, not a full synopsis. Concise + witty. Optional small date/context pill (e.g. `SATURDAY 9:05`).
- Pets/people: prefer flattering stills (mouth closed; no mid-squawk / mid-word if a face is the hero) unless the “disaster look” *is* the hook (wet bird, cone, etc.).
- Deliver: local `thumb/` + attach in chat; upload Drive beside the Short when a folder already exists; hold YouTube until the show owner says go.

## Steps
1. Pick the single strongest still (user-named preferred — e.g. bird in carrier).
2. Draft 2–3 WHY stacks; pick the punchiest; keep an alt file.
3. Compose 1080×1920 with left same-image fade + type + optional pill.
4. Visual QA (Read the JPG): type readable, face clear, no stretch, no black box.
5. Save under the project `thumb/` and mention in JTUBE.md; Drive upload if the Short folder is live.
6. Offer the primary + one alt; lock whichever the show owner picks.
